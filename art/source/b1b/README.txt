B1B Meadow terrain prototype

Sprites: copy into the game sprites directory for a drop-in test. Grass is byte-identical to approved B-organic. Earth sheets preserve original 80x16 dimensions, five 16x16 frames and exact alpha masks, anchors and frame order. Default uses v1. Optional variants v0-v7 retain same layout and require engine selection; choose using stable tile/edge/band coordinates, not per-frame randomness. v0/v7 are plain, v1/v2/v5 sparse, v3/v6 moderate, v4 large. Suggested weights 25% plain, 40% sparse, 25% moderate, 10% large. Each full band is only 4 pixels tall; larger continuous rocks and grass overhang across multiple bands would require coordinated overlays or renderer changes. No new cast shadows. Preview is an external mockup, not engine-tested. Do not rerun placeholder generator over these files.
